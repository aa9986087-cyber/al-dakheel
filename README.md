# الدخيل — طائرة الصقر

لعبة جماعية أونلاين للعائلة والأصدقاء: طاقم على متن **طائرة الصقر** العربية، وبينهم **دخيل** (أو أكثر). الطاقم ينجز المهام ويكشف الدخيل في **المجلس**، والدخيل يُقصي الركاب بهدوء ويعطّل الأنظمة ويتنقل عبر فتحات سرية.

- رؤية علوية 2D مع ضباب رؤية وإضاءة فوانيس، ورسم إجرائي كامل (بلا صور خارجية): مجلس بجلسة أرضية وسجاد، ضيافة بدلال وتمر، قمرة قيادة، اتصالات، مولدات، مراقبة بكاميرات، محركات، عيادة، مخزن، خزان وقود.
- واجهة عربية RTL، تعمل على الجوال (عصا تحكم وأزرار) والكمبيوتر (لوحة المفاتيح).
- من ٣ إلى ١٢ لاعبًا (الأفضل ٥ فأكثر)، غرفة برمز أو رابط.

## التشغيل محليًا

يتطلب Node.js 22 أو أحدث.

```bash
npm install
npm run dev        # http://localhost:8787
npm test           # اختبارات المنطق + اختبار WebSocket حقيقي
```

للتجربة وحدك: افتح عدة تبويبات (أو نافذة خاصة) على `http://localhost:8787`، أنشئ غرفة في الأول، وانضم بالرمز من الباقي. للعب مع أجهزة البيت على نفس الشبكة: افتح `http://<IP-جهازك>:8787` من الجوالات.

## النشر المجاني (Cloudflare Workers + Durable Objects)

```bash
npx wrangler login
npm run deploy     # يرفع الواجهة والخادم معًا
```

أو من لوحة Cloudflare: **Workers & Pages → Create → Import a repository**، اختر هذا المستودع، واترك أمر النشر `npx wrangler deploy`. بعدها كل دفع على `main` ينشر تلقائيًا. الرابط بالشكل `https://al-dakheel.<حسابك>.workers.dev`.

للتجربة داخل بيئة Cloudflare المحلية: `npm run cf:dev`.

بديل: أي استضافة Node (VPS، Render، Railway) بأمر `npm start` والمنفذ من `PORT`.

## طريقة اللعب

| | |
|---|---|
| **الطاقم** | أنجز مهامك (تظهر حلقة ذهبية عند محطاتها). بلّغ عن أي راكب مُقصى. |
| **الدخيل** | إقصاء بزر 🗡️ (له تهدئة)، تخريب ⚡ (الأنوار، الاتصالات، تسرّب الوقود، إغلاق الأبواب)، والفتحات السرية 🕳️. |
| **المجلس** | البلاغ أو جرس الطوارئ على طاولة المجلس يفتح نقاشًا ثم تصويتًا. التعادل أو التخطي = لا طرد. |
| **الأرواح** | من يُقصى يكمل مهامه كروح، يرى الجميع، ويتكلم مع الأرواح فقط. |
| **الفوز** | الطاقم: كل المهام أو كشف كل الدخلاء. الدخلاء: التساوي مع الطاقم أو انفجار خزان الوقود. |

التحكم: الأسهم/WASD للحركة، `E` استخدام، `R` بلاغ، `Q` إقصاء، `V` فتحة، `F` تخريب، `M` الخريطة.

## بنية المشروع

| المسار | المسؤولية |
|---|---|
| `server/room.js` | منطق الغرفة الموثوق: الأدوار، الحركة، الإقصاء، الاجتماعات، التصويت، التخريب، الفوز |
| `server/worker.js` | Cloudflare: Worker + Durable Object لكل غرفة |
| `server/dev.mjs` | خادم Node للتطوير والاختبار والاستضافة البديلة |
| `public/shared/` | كود مشترك بين الجوال والخادم: الإعدادات، الخريطة، التصادم والرؤية |
| `public/client/` | الواجهة: الشبكة، التحكم، الرسم، المهام المصغرة، الصوت |
| `test/` | اختبارات `node --test` |
| `docs/ARCHITECTURE.md` | شرح معمارية اللعب الجماعي ولماذا اخترناها |

## إضافة مهمة جديدة

أضف سطرًا في `MAP.tasks` داخل `public/shared/map.js` (المعرّف، الاسم، الغرفة، الموقع، النوع). الأنواع الجاهزة: `hold` ، `sequence` ، `slider` ، `wires` ، `switches` ، `clicks` ، `scan` ، `code`. لنص خاص بالمهمة أضف تعريفًا في `VARIANTS` داخل `public/client/tasks.js`.
